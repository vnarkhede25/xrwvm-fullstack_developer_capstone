# Dealership Reviews – IBM Full Stack Capstone Project

## Project Description
This project is a full-stack dealership review application developed as part of the IBM Full Stack Software Developer Capstone.

Users can browse car dealerships, view dealership details, register and log in, and submit reviews about dealerships.

## Technologies Used
- Python and Django
- React.js
- Node.js and Express
- MongoDB
- HTML, CSS and JavaScript
- REST APIs
- Docker
- GitHub Actions

## Main Features
- User registration and login
- User logout
- View all dealerships
- Filter dealerships by state
- View dealership details and reviews
- Submit dealership reviews
- Car makes and models
- Review sentiment analysis
